# 📱 Consulta de API com React Native e Axios

Este repositório contém uma aplicação mobile desenvolvida em **React Native** com **Expo**, criada como parte de uma atividade prática. A aplicação realiza a consulta a uma API pública e exibe o conteúdo em ecrã com tratamento de estados.

---

## 🚀 Funcionalidades

- 📡 **Consumo de API pública:** Requisição HTTP utilizando a biblioteca `axios` para o endpoint `https://jsonplaceholder.typicode.com/posts/1`.
- ⏳ **Indicador de carregamento:** Apresentação de uma mensagem e um componente `ActivityIndicator` enquanto os dados estão a ser procurados.
- 📄 **Exibição dos dados:** Apresentação do **título** e **conteúdo (body)** da publicação retornada.
- 🛡️ **Tratamento de erros:** Bloco `try/catch` para capturar e tratar eventuais falhas de conexão ou na resposta da requisição.

---
